  io.prints("\n"+vars(ct.CURRENT))

TypeError: can only concatenate str (not "dict") to str

This specific Python error, TypeError: can only concatenate str (not "dict") to str, happens because you are trying to use the string concatenation operator (+) to join a string ("\n") with the result of vars(ct.CURRENT), which is a dictionary.

In Python, the + operator for strings is strictly for joining one string to another string. It does not automatically convert other data types (like dictionaries) into strings before joining.
💡 How to Fix It

You need to explicitly convert the dictionary returned by vars(ct.CURRENT) into a string before you can concatenate it with "\n". The simplest way to do this is using the built-in str() function.
Python

io.prints("\n" + str(vars(ct.CURRENT)))

🧐 Why vars() Returns a Dictionary

The built-in Python function vars() is used to return the __dict__ attribute of an object, which is a dictionary containing the object's writable attributes.

    ct.CURRENT is likely an object (like a class instance or module).

    vars(ct.CURRENT) returns a dictionary of the form:
    Python

    {'attribute_name_1': value_1, 'attribute_name_2': value_2, ...}

When you try to run:
Python

"\n" + {'key': 'value'}  # Example of the failed operation

Python raises the TypeError because the + operator doesn't know how to combine a string and a dictionary. Using str() converts the dictionary into its string representation, which can then be concatenated.

2. Відмінність між str() та repr()

У Python є дві основні функції для отримання рядкового представлення об'єкта, і важливо розуміти їхню різницю:
Функція	Призначення	Аудиторія

3. Як це працює для ваших власних класів

Коли ви створюєте власний клас (об'єкт), ви можете контролювати, яке рядкове представлення він повертатиме, перевизначаючи спеціальні методи (magic methods) всередині класу:

    __str__(self): Визначає, що має повертати функція str() і що виводиться при використанні print(). Повинно повертати рядкове представлення, орієнтоване на користувача.

    __repr__(self): Визначає, що має повертати функція repr(). Повинно повертати рядкове представлення, орієнтоване на розробника.

Якщо ви визначите тільки __repr__, Python використає його як резервний варіант для __str__. Рекомендується завжди визначати __repr__.
Python

class Точка:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    # Офіційне представлення (для розробників)
    def __repr__(self):
        return f"Точка(x={self.x}, y={self.y})"

    # Дружнє представлення (для користувачів)
    def __str__(self):
        return f"({self.x}, {self.y})"

p = Точка(10, 20)

print(p)         # Викликає __str__ -> (10, 20)
print(str(p))    # Викликає str()  -> (10, 20)
print(repr(p))   # Викликає repr() -> Точка(x=10, y=20)

А якщо таких методів немає, що тоді роблять ці функції?

Якщо ви не визначили спеціальні методи __str__ та __repr__ у вашому класі, Python використовує стандартні реалізації цих функцій.
1. Поведінка repr() (Без __repr__)

Якщо ви не визначили метод __repr__(self), функція repr() (а також інтерактивний інтерпретатор) поверне базове (default) рядкове представлення об'єкта.

Цей рядок зазвичай має такий формат:
<назва_класу object at адреса_в_пам’яті>
Приклад
Python

class МійКлас:
    # __init__ та __repr__ не визначені
    pass

об'єкт = МійКлас()
print(repr(об'єкт))
# Вивід буде приблизно таким: <__main__.МійКлас object at 0x10d343c40>

Це представлення корисно для налагодження, оскільки воно показує точний тип об'єкта та його унікальну адресу в пам'яті (0x...), що допомагає ідентифікувати, з яким саме екземпляром ви працюєте.
2. Поведінка str() та print() (Без __str__)

Якщо ви не визначили метод __str__(self), функція str() і, відповідно, функція print() (яка неявно викликає str()), використовують результат методу __repr__.

    Якщо __repr__ визначено, то str() використовує його вивід.

    Якщо __repr__ НЕ визначено, то str() також повертає те саме базове представлення адреси в пам'яті, що й repr().

Приклад
Python

class ІншийКлас:
    # Не визначено ні __str__, ні __repr__
    pass

об'єкт_2 = ІншийКлас()

# Оскільки немає __str__, викликається __repr__,
# а оскільки немає __repr__, використовується базове представлення.
print(str(об'єкт_2))
# Вивід буде такий самий, як і для repr(): <__main__.ІншийКлас object at 0x...>

print(об'єкт_2)
# Теж саме: <__main__.ІншийКлас object at 0x...>

🔑 Висновок

Коротше кажучи, Python завжди використовує __repr__ як резервний (fallback) варіант для __str__. Якщо обидва не визначені, ви отримуєте базовий рядок, що містить назву класу та адресу об'єкта в пам'яті.

Ну, цього ж замало. Треба щоб був перелік полів і вони в свою чергу усі перетворені на str, щоб там не було. наприклад response-обєкт, або response від curl_cffi

Ви абсолютно праві. Якщо об'єкт містить інші об'єкти (наприклад, поля, які є словниками, списками чи іншими складними типами), простого str(vars(об'єкт)) буде недостатньо, оскільки внутрішні об'єкти залишаться без належного перетворення.

Наприклад, якщо одне з полів є Response об'єктом, його значення в словнику, отриманому через vars(), буде виглядати як <Response [200]>, а не як детальний рядок, який ви хочете.

Щоб гарантувати, що всі поля об'єкта перетворені на рядки, потрібно ітеративно обробити словник, отриманий від vars(), і застосувати str() до значення кожного поля.

Ось як це можна зробити:
🛠️ Рішення: Функція для глибокого перетворення на String

Ви можете написати просту функцію, яка бере словник, і перетворює всі його значення на рядки.
Python

def object_to_string_dict(obj):
    """
    Повертає словник, де ключі - це назви полів obj, 
    а значення - їхнє рядкове представлення (str()).
    """
    try:
        # 1. Отримуємо словник полів об'єкта
        obj_vars = vars(obj)
    except TypeError:
        # Якщо vars() не може працювати з об'єктом (наприклад, якщо це вбудований тип без __dict__)
        return {"error": "Об'єкт не підтримує функцію vars()"}

    result_dict = {}
    
    # 2. Ітеруємося по всіх парах ключ-значення
    for key, value in obj_vars.items():
        # 3. Примусово перетворюємо значення на рядок і зберігаємо
        result_dict[key] = str(value)
        
    return result_dict

Припустимо, у вас є об'єкт ct.CURRENT із такими полями:

❗ Примітка щодо деталізації

Якщо ви хочете, щоб складні об'єкти (наприклад, Response або інші об'єкти вашого фреймворку) перетворювалися на дуже детальні рядки (наприклад, включали тіло відповіді, заголовки тощо), вам потрібно:

    Або змінити реалізацію методу __str__ у класі цього складного об'єкта, щоб він повертав потрібну деталізацію.

    Або спеціально обробляти відомі типи об'єктів (наприклад, для Response викликати його метод .text або .json()) всередині вашої функції.

Для загального випадку, функція object_to_string_dict є найкращим рішенням для перетворення всіх полів на рядки.


> curl_cffi який використовує? Що я можу дьорнути з нього у текстовій формі? 

Ви маєте на увазі, який саме транспортний протокол і реалізацію використовує бібліотека curl_cffi і які саме дані ви можете отримати з її об'єктів у текстовій формі.
💻 1. Яку технологію використовує curl_cffi?

Бібліотека curl_cffi є Python-обгорткою навколо потужної та універсальної бібліотеки cURL.

    Транспортна основа: Вона використовує оригінальну бібліотеку libcurl (написану на C) через інтерфейс CFFI (C Foreign Function Interface). Це дозволяє їй ефективно використовувати всі можливості та налаштування cURL.

    Протоколи: Завдяки libcurl, curl_cffi підтримує широкий спектр протоколів, але в контексті веб-запитів це, перш за все:

        HTTP/1.1

        HTTP/2 (включаючи повну підтримку HTTP/3 в нових версіях libcurl).

        HTTPS (включаючи TLS/SSL).

    Особливість: Головна перевага curl_cffi полягає в тому, що вона може використовувати Mozilla's NSS (Network Security Services) замість стандартного OpenSSL для TLS/SSL. Це дозволяє їй емулювати поведінку різних веб-браузерів (наприклад, Chrome, Edge), обходячи багато систем захисту, які перевіряють цифрові відбитки TLS (TLS fingerprints).

📄 2. Що можна отримати в текстовій формі?

Після виконання запиту (наприклад, response = requests.get(...)), об'єкт response від curl_cffi має багато атрибутів, які ви можете отримати у вигляді рядків (тексту) для аналізу або друку.

Ось основні з них, які є в текстовому форматі або легко перетворюються на нього:
Атрибут	Призначення	Формат даних
response.text	Тіло відповіді (основний вміст сторінки/даних), декодоване відповідно до кодування, вказаного в HTTP-заголовках.	str (рядок)
response.content	Тіло відповіді у сирому (байтовому) вигляді, якщо потрібна ручна обробка кодування.	bytes (байтовий рядок)
response.headers	Заголовки відповіді від сервера (наприклад, Content-Type, Set-Cookie).	dict (словник, легко перетворюється на str)
response.url	Кінцевий URL-адреса, з якої була отримана відповідь (з урахуванням редиректів).	str (рядок)
response.status_code	Код стану HTTP (наприклад, 200, 404, 500).	int (ціле число, легко перетворюється на str)
response.reason	Текстове пояснення коду стану (наприклад, "OK", "Not Found").	str (рядок)
response.cookies	Куки (cookies), отримані у відповідь.	RequestsCookieJar (об'єкт, що містить куки)
response.elapsed	Час, витрачений на запит.	timedelta (об'єкт часу)


Як перетворити це на один текст?

Щоб отримати повний перелік полів у текстовій формі, ви можете використати підхід, схожий на той, що обговорювався раніше (з використанням vars()):
Python

response = requests.get("https://example.com") # Ваш запит

all_fields_as_str = {
    key: str(value) 
    for key, value in vars(response).items() 
    if not key.startswith('_') # Виключити внутрішні (приватні) поля
}

# Тепер all_fields_as_str - це словник, де всі значення - рядки.
print(all_fields_as_str)
